# Jamrah جَــمْــرَه

*ember of productivity*

Jamrah is a local-first productivity app for Windows — tasks, pomodoro sessions, and calendar, all stored locally on your machine (SQLite). No accounts, no cloud, no tracking.

> Source code is now maintained in a private repository.
> Download the latest version from **[Releases](../../releases)**.

## Download

Go to **Releases** above and download the latest `Jamrah.exe`.
